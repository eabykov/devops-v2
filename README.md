### Курс обучения DevOps

Курс для тех, кто начинает с нуля. Каждая тема — это теория простым языком, вопросы с ответами для самопроверки и практические задания, которые нужно выполнить руками

### Как проходить курс

1. **Идти по порядку.** Каждая тема опирается на предыдущие: без темы 1 не понять тему 4, без темы 4 — тему 5
2. **Делать практику, а не читать её.** Теорию можно понять за вечер, инженером она не делает. Все команды нужно выполнить самому и получить свой результат
3. **Ломать специально.** Почти в каждой теме есть задание «сломай и почини». Не пропускай их: работа инженера начинается там, где что-то перестало работать
4. **Проверять себя.** В конце каждой темы список «Проверь себя». Если не можешь объяснить пункт своими словами — вернись к нему

### Сквозной проект: сервис «Заметки»

Через весь курс проходит одно приложение — простой веб-сервис «Заметки». Каждая тема добавляет к нему новый слой:

| Тема | Что происходит с «Заметками» |
|------|------------------------------|
| 1 | Запускаем на своей машине, оформляем systemd-сервисом |
| 2 | Ставим спереди nginx, включаем HTTPS |
| 3 | Кладём в репозиторий, настраиваем автоматические проверки |
| 4 | Упаковываем в контейнер, поднимаем вместе с базой |
| 5 | Запускаем в трёх копиях, обновляем без простоя |
| 6 | Выносим на сервер в интернете |
| 7 | Разворачиваем всю инфраструктуру одной командой |
| 8 | Добавляем метрики, дашборд и алерты |
| 9 | Убираем пароли из кода, деплоим автоматически из git |

К концу курса у тебя останется репозиторий, который можно показать на собеседовании
